# AI-Interview-Preparation-Platform
A Full Stack AI Interview Preparation Platform built with ReactJS, Node.js, Express.js, and MongoDB. Features include JWT authentication, AI-powered interview question generation, coding practice, resume management, analytics dashboard, and responsive modern UI.

# InterviewAI Pro

## Overview

InterviewAI Pro is a Full Stack AI Interview Preparation Platform designed to help students and job seekers prepare for technical interviews effectively. The platform provides AI-generated interview questions, coding practice modules, resume management, progress analytics, and a modern dashboard experience.

## Features

### User Authentication

* User Registration
* Secure Login
* JWT Authentication
* Protected Routes
* User Profile Management

### AI Interview Question Generator

* Generate role-based interview questions
* Difficulty-level selection
* Save generated questions
* Categorized interview preparation

### Coding Practice Module

* Coding problem library
* Easy, Medium, and Hard difficulty levels
* Progress tracking
* Practice history

### Resume Management

* Resume Upload
* Resume Storage
* Resume Viewing
* Resume Deletion

### Analytics Dashboard

* Questions Practiced
* Coding Problems Solved
* Activity Tracking
* Learning Progress Visualization

### Responsive Design

* Mobile Friendly
* Modern Dashboard UI
* Dark Mode Support
* Clean User Experience

## Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/InterviewAI-Pro.git
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```
